# 帰り道ナビ

日本大学文理学部から桜上水駅・下高井戸駅を経由して笹塚駅に向かう、仮ダイヤの比較アプリです。
`index.html` をブラウザで開くだけで動きます。インストールやAPIキーは不要です。

## ファイル

- `index.html`: 結論、日時・所要時間の入力、2駅の比較
- `style.css`: スマートフォン対応のスタイル
- `script.js`: 毎時繰り返す仮ダイヤ、日時計算、列車探索、画面更新
- `tests/app.test.cjs`: Node.js標準機能を使う自動テスト

## 判断の流れ

1. 現在時刻モードではブラウザの日時を秒単位で取得。テストモードでは指定日時を固定する。
2. 大学の出発日時に、構内移動込みの所要時間を加算する（初期値は9分・8分）。
3. 乗車可能時刻以降、大学出発から2時間以内に発車する全列車から、笹塚に最も早く着く列車を駅ごとに選ぶ。
4. 各駅の到着時刻を比較する。同着なら両駅の列車と出発期限を表示する。
5. 発車日時から所要時間を引いて大学の出発期限を算出。2種類のカウントダウンは対象日時との差から毎回計算する。
6. 推奨列車より後に発車する最初の列車と、乗り逃した場合に最も早く着く列車を検索する。乗車場所にいる前提なので所要時間は再加算しない。

データ取得は `trainProvider.getTrains()`、判断は `calculateRoute()` と `compareRoutes()` に分離しています。
実際の運行・追い越しを再現するデータではありません。仮ダイヤを毎時、24時間繰り返します。

## 動作確認

「試してみる」ボタンは表示中の日付を使い、所要時間を9分・8分に戻します。

| 大学出発時刻 | 確認する結果 |
| --- | --- |
| 18:03:00 | 下高井戸18:13発・笹塚18:18着。桜上水より2分早い |
| 18:07:00 | 桜上水18:20発・笹塚18:25着。下高井戸より3分早い |
| 18:16:00 | 桜上水18:30発の急行が18:35着。先発18:25の各停より10分早い |
| 18:50:00 | 両駅とも翌時の08分着。両駅の発車時刻・出発期限を表示 |
| 18:06:00 → 18:06:01 | 桜上水18:15発に一致して乗車可能 → 1秒遅れで18:20発に更新 |
| 18:07:00の乗り逃し | 桜上水の次は18:25発・18:45着で20分遅い。最早は18:30発・18:35着で10分遅い |
| 23:58:00 | 列車や到着時刻に「翌日」を表示 |

日時欄を編集するとテストモードになります。「現在時刻に戻す」で実時刻に戻ります。
テストモードでは待っても値が変わらず、現在時刻モードでは毎秒更新することを確認してください。
タブをしばらく非表示にして戻すと、実時刻から残り時間と推奨を再計算します。
ブラウザの開発者ツールで幅320px・375pxを選び、横スクロールせず入力・ボタン操作できることも確認してください。

自動テストはフォルダー内で以下を実行します。

```text
node --test tests/app.test.cjs
```

テストは日時・探索とDOMの代替によるイベント・差分更新を検証します。
実ブラウザの描画や端末の日時入力UIを検証するものではありません。
